🔐 Accesso con GitHub

Per accedere alla dashboard serve autenticarsi con GitHub. Il sistema mostra un codice di 8 caratteri da inserire su github.com/login/device.

  1. Clicca Accedi con GitHub qui sotto.
  2. Copia il codice di 8 caratteri che appare (es. WDXB-MZ99).
  3. Vai su github.com/login/device e inserisci il codice.
  4. Approva + 2FA con Microsoft Authenticator.
  5. Torna qui, sei dentro. 🎉
